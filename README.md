BMI Calculator
A simple web-based BMI calculator built with Python and Flask.
This application allows users to input their height and weight to instantly receive their BMI score and corresponding health category.
FeaturesUser Input: Simple and clear form to enter height in cm and weight in kg.

Structure of the directory:
|-- /static
|   |-- style.css
|-- /templates
|   |-- index.html
|-- app.py
|-- README.md
Setup and Usage
Follow these steps to run the application on your local machine.
Clone the Repository :git clone github.com/tworaisedtox/bmi_calc
cd bmi-calculator
Install Dependencies: Ensure you have Python 3 installed.
Then, install Flask using pip.pip install Flask
Run the Application: Execute the app.py script from your terminal.python app.py
Access in Browser:Once the server is running, open your web browser and navigate to: http://127.0.0.1:5000
You should now see the BMI Calculator and be able to use it.
