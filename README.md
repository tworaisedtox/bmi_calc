<div align="center">BMI Calculator 🏋️‍♂️</div><p align="center">A simple web-based BMI calculator built with Python and Flask. This application allows users to input their height and weight to instantly receive their BMI score and corresponding health category.</p>✨ Features👤 User Input: Simple and clear form to enter height in cm and weight in kg.⚡ Instant Calculation: Backend powered by Flask processes input in real-time.📊 Categorized Results: Displays the BMI value and its category (Underweight, Normal, Overweight, Obese).🎨 Color-Coded Feedback: The result is color-coded for quick interpretation.📱 Responsive Design: A clean interface that works well on all screen sizes.🛠️ Technologies Used📂 Project Structure/bmi-calculator

Getting StartedFollow these steps to run the application on your local machine.PrerequisitesPython 3.6+pip (Python package installer)Installation & SetupClone the Repository:git clone [https://github.com/tworaisedtox/bmi_calc](https://github.com/tworaisedtox/bmi_calc)
cd bmi_calc 
Install Dependencies:Install Flask using pip.pip install Flask
Run the Application:Execute the app.py script from your terminal.python app.py
Access in Browser:Once the server is running, open your web browser and navigate to:➡️ http://127.0.0.1:5000You should now see the BMI Calculator live!
